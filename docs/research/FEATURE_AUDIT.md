## 2. Карта функций

### 2.1 Холст (Canvas) [Д]

| Параметр | Значение |
| --- | --- |
| Навигация | pinch-zoom, pan, двойной тап = вписать в экран |
| Связь палитры и фото | тап по свотчу подсвечивает точку; двойной тап центрирует |
| Display menu | маркеры на фото / только в палитре, номера, соединительные линии, Frame mode (свотчи по рамке рядом с местом взятия) |
| Нижняя панель | ресайз перетаскиванием, сворачивание тапом; высота запоминается **для каждого вида отдельно** |
| Миниатюры видов | живые превью всех режимов анализа над вкладками, ресайз до иконок |
| Сравнение с оригиналом | удержание кнопки изображения в любом виде анализа [V 1.4] |

### 2.2 Пипетка (Picking Colors) [Д]

| Параметр | Значение |
| --- | --- |
| Вызов | кнопка-пипетка с лупой или long-press в любом месте |
| Увеличение лупы | настраивается в Display menu, «pixel-accurate zoom» [V 1.3] |
| Размер выборки | 1×1, 3×3, 5×5 [V 1.4], 11×11 [V 2.0.0] — усреднение |
| Отмена | увести палец за пределы изображения (support) |

### 2.3 Автоизвлечение (Auto-Extract) [Д]

| Категория | Описание разработчика |
| --- | --- |
| Dominant | самые частые цвета, по убыванию процента |
| Range | образцы по всей шкале яркости от тёмного к светлому |
| Accents | отличающиеся, выделяющиеся цвета |
| Управление | слайдер Count, «Add All», переключатель «Auto-extract on load» (вкл. по умолчанию) |
| По умолчанию [Н] | Dominant 6, Range 12, Accents 6 цветов; у Dominant проценты площади на свотчах |
| Поведение [Н] | Range идёт от тёмного к светлому и берёт разные оттенки на одной светлоте; Dominant не сливает близкие цвета (бумага флэша = два свотча 45 % и 21 %) |
| Место на фото | каждый извлечённый цвет получает маркер в месте, где он найден (S2) |
| Ограничения | бесплатный тариф ограничен по числу извлечений (S5, лимит не указан) |

### 2.4 Карточка цвета: Details / Compare [Д]

- **Details**: value (светлота), hue, saturation, температура, комплементарный цвет, коды.
- **Compare**: второй цвет из палитры, с фото или из color picker. Показывает относительную разницу по value, температуре, hue, saturation и «perceptual difference» (S3; формула ΔE не указана).
- **Коды цвета** (Settings): HEX, RGB, CMYK, HSL, HSV, LAB, XYZ, xyY.
- **Имена цветов**: Creative (база «поэтичных» названий) или Standard (по hue/saturation/lightness).

### 2.7 Values (карта тонов) [Д], [S4]

| Параметр | Значение |
| --- | --- |
| Values | число уровней, максимум 20 [V 1.6.1]; **по умолчанию 9** [Н] |
| Smoothing | None / Subtle / Strong (предсглаживание) |
| Brightness | сдвиг всех уровней светлее/темнее с сохранением соотношений; по умолчанию 0 [Н] |
| Show Hue | тонирует каждый уровень исходным оттенком |
| False color | режим ложных цветов [V 2.0.7] |
| Алгоритм | «Smart Grouping»: кластеризация значений по распределению в конкретном фото вместо равных интервалов 0–255 (S4). [Н]: ближе всего к 1-D k-means по гистограмме luma с весом по числу пикселей, цвет уровня = средняя luma; совпадение с нашей реализацией 99,8–100 % пикселей на трёх фото и 89,9 % на пейзаже, поэтому алгоритм воспроизведён не полностью |
| Advanced [Н] | чекбокс Smart Grouping (вкл. по умолчанию; выкл. = равные интервалы), гистограмма с перетаскиваемыми маркерами порогов, процент площади на каждом уровне, «Show 1-10 Scale» |
| Smoothing по умолчанию [Н] | None; Show Hue выключен |
| Взаимодействие | тап по свотчу уровня подсвечивает его области; long-press = мультивыбор [V 1.7.2] |

### 2.8 Notan [Д]

| Параметр | Значение |
| --- | --- |
| Balance | порог свет/тень; **по умолчанию = медиана яркости изображения**. [Н]: медиана luma, совпадение точное на 4 фото; на фото с большим однородным фоном фон рассыпается в шум |
| Smoothing | предсглаживание |
| Invert | инверсия |
| Варианты | на SEO-странице упомянут режим 2 или 3 значений (S6) |

### 2.9 Temperature [Д]

Оранжевый = тёплое, синий = холодное. Balance сдвигает порог между тёплым и холодным, Smoothing предсглаживает (по умолчанию None). Своих цветов карты можно задать [V 2.0.7]. [Н]: карта непрерывная, а не двухцветная: синий → серо-сиреневый (нейтраль) → светло-оранжевый → красный; светлота исходника не сохраняется. Формула «температуры» не установлена.

### 2.10 Simplify [Д], [V]

| Параметр | Значение |
| --- | --- |
| Вкладки в вебе [Н] | только «Block-In»; стили подписаны **Clusters / Regions / Poster** (внутри `clustering` / `graphBased` / `posterize`) |
| Details | меньше деталей = крупнее формы; [Н] 9 позиций, по умолчанию 5-я; на пейзаже 1K: Less = 22 цвета, середина = 177, More = 1082 |
| Smoothing | None / Subtle / Strong; по умолчанию None [Н] |
| Clustering (по умолчанию) | «группирует похожие цвета в области» |
| Graph | «находит естественные края и границы», работает дольше, сохраняет края, которые Clustering теряет |
| Posterize | дискретные уровни цвета; улучшен в 2.0.5 |
| Edges overlay | наложение краёв [V 2.0.8] |
| Picked colors | пипетка на упрощённом изображении [V 1.6.1, 2.0.8] |
| Open in Normal View | упрощённое фото становится новым референсом; в вебе вместе с Export в меню Actions [Н] |
| Время на вебе [Н] | 1,3–2,7 с на фото 1K, интерфейс в это время заморожен |
| Отличие по заявлению | «не размытие, а чистые формы с чёткими границами» |

### 2.11 Drawing [Д], [V 2.0.1]

Вкладка внутри Simplify. **Sketch**: детальный «карандашный» рисунок с текстурами. **Contours**: чистые линии крупных границ. Слайдеры Line (light ↔ dark) и Stroke (thin ↔ thick) обновляются в реальном времени, есть Invert.

[Ф]: реализовано нейросетями `anime_style.ort` и `contour_style.ort` (по 17,2 МБ) через ONNX Runtime, вход уменьшается до 512 px на телефоне и 768 px на десктопе. Ползунки Line/Stroke, видимо, работают поверх готового выхода модели. [Н]: в веб-интерфейсе 2.0.5 вкладки Drawing нет.

### 2.12 Смешивание красок [Д]

| Параметр | Значение |
| --- | --- |
| Цель | Match Color, автоматически сдвигается в гамут палитры пользователя |
| Рецепт | доли красок как отношение (3:1) или проценты |
| Обратная связь | фото реального замеса камерой → советы «добавь белил», «добавь синего» |
| Альтернативы | Best only / Close (ΔE ≤ 5) / Broader (ΔE ≤ 15), листаются карточками |
| Virtual mixing | «что получится», без камеры |
| Подсказка красок | предложить краску для более точного совпадения [V 2.0.2] |
| Ограничения | только кроющие краски (масло, акрил, гуашь); акварель отдельным режимом «осветление водой» [V 2.0.10] |

### 2.13 Палитры красок [Д]

Несколько палитр-вкладок; пресеты Split Primary, Zorn, Limited, Primary Triad; поиск по имени, альтернативному имени и пигменту (PY42); до 30 красок в палитре (было 10 → 20 [V 2.0.0] → 30 в текущей документации); каталоги реальных брендов масла и акрила [V 2.0.7]; индикатор кроющей способности; бейдж «измерено по спектральному отражению».

### 2.14 Экспорт [Д]

| Экспорт | Опции |
| --- | --- |
| Color Map (Normal View) | маркеры, палитра с фото или без, Frame mode, линии, номера |
| Color Details | свотч, номер, имя, код, рецепт, предсказанный цвет смеси; список или таблица; сортировка по номеру, светлоте, hue; **PNG или CSV** |
| Виды анализа | упрощённое фото, value study, notan, temperature map |
| Куда | сохранение в общий альбом [V 1.5] / поделиться |

Разрешение экспорта [Н]: на вебе все виды и Color Map экспортируются в размере рабочей копии, длинная сторона не больше **1080 px** (фото 4032×3024 → 1080×810). Скачивание сразу, без диалога, кроме Color Map: у него окно с превью, Show Markers, Show Numbers, Marker Size, Show Image, цвет фона, палитра None / Bottom / Distributed, Connection Lines. В мобильных версиях разрешение не проверено [—].

### 2.15 Проекты, сессии, настройки

- Проекты: изображения, палитры красок, данные о работе [V 2.0.8]; синхронизация iCloud; «поделиться проектом одним файлом» [V 2.0.10].

- Тёмная тема [V 2.0.7]; Choose from File и Photo Library [V 1.7.2].

## 3. Высокое разрешение и офлайн

| Вопрос | Что известно | Статус |
| --- | --- | --- |
| Максимальный размер фото | на вебе 12 МП грузится без ошибок; на мобайле не проверено | [Н] / [—] |
| Downscale для анализа | на вебе фото сразу уменьшается до длинной стороны 1080 px, меньшие фото не увеличиваются | [Н] |
| Скорость | «analysis happens instantly» (S6, маркетинг). На вебе в Chromium 141 headless на сервере (не iPhone, на Safari не переносится): Notan и Temperature 0,4 с, Values 0,75 с, Simplify 1,3–2,7 с, всё в главном потоке | [Н] |
| Офлайн iOS/Android | обработка локальная, значит анализ должен работать без сети; покупки и синк требуют сети | вывод, [—] |
| Офлайн веб | **не работает**: Service Worker не регистрируется (`flutter_service_worker.js` → 404, загрузчик без настроек SW), перезагрузка без сети → `ERR_INTERNET_DISCONNECTED`. Движок (CanvasKit, Firebase, ONNX Runtime) грузится с внешних CDN | [Ф], [Н] |

## 4. Что проверить не удалось

1. Значения по умолчанию и диапазоны в мобильных версиях (на вебе сняты: Values 9 из 2–20, Details 9 позиций, Smoothing None, Count 6/12/6).
2. Какие функции закрыты в мобильных версиях без подписки.
3. Время обработки и поведение мобильных версий на 12 и 48 МП.
4. Формулы: «perceptual difference», температура, алгоритм Regions и Clusters (Notan восстановлен; Values воспроизведён близко, но на пейзаже совпадение 89,9 %).
5. Формат файла «share project».
6. Drawing: в веб-версии 2.0.5 вкладки нет, проверить можно только в iOS-приложении.

Как снять эти ограничения, описано в TECHNICAL_RESEARCH.md, раздел 7.
